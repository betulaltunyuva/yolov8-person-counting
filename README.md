# İnsan Sayımı Projesi (YOLOv8)

Bu proje, video veya kamera görüntüsü üzerinden **gerçek zamanlı insan sayımı** yapmak amacıyla geliştirilmiştir.  
YOLOv8 nesne tespit modeli kullanılarak görüntülerdeki insanlar algılanmakta ve toplam kişi sayısı hesaplanmaktadır.

## 🚀 Kullanılan Teknolojiler
- Python 3.10
- OpenCV
- YOLOv8 (Ultralytics)
- PyTorch
- Gradio

## 📌 Proje Özellikleri
- Video veya kamera üzerinden insan tespiti
- Gerçek zamanlı kişi sayımı
- YOLOv8 ile yüksek doğruluk
- Basit ve anlaşılır Python kod yapısı
